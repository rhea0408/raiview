## [1.0.0] — 2026-06-09

### Initial release

- Review git diffs or active files with one click
- Structured findings grouped by severity — Critical, Warning, and Suggestion
- Multi-turn follow-up conversations (up to 20 exchanges per session)
- Persistent session history (last 5 sessions saved automatically)
- Supports Ollama (local and remote), OpenAI, and Anthropic Claude
- Switch provider or model mid-session without losing conversation history
- Enhanced Reviewer: build a code-review-optimized Ollama model from any base model
- GPU memory management: manual and auto-unload for Ollama models
